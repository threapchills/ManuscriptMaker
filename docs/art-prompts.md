The initial shared generation brief was 14th-century illuminated manuscript gouache with ink contours, burgundy, gold, indigo, and sage pigments; isolated subjects on genuine transparent backgrounds; no typography, paper rectangle, watermark, or UI. This is a summary of the original briefs: a usage interruption prevented preserving the full verbatim tool transcript here.

The user's later instruction supersedes individual-asset generation. Future artwork uses transparent 8×4 modular sheets; save exact prompts and row-major manifests before calling generation. See `ART_PIPELINE.md`.
